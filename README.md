## Características

* **Horario Personalizado:** Visualización semanal y diaria de bloques de clases con alertas de sala y hora.
* **Malla Curricular:** Exploración de prerrequisitos, asignaturas aprobadas y simulación de avance académico.
* **Catálogo de Profesores y Asignaturas:** Consulta de paralelos, salas, sedes y evaluaciones docentes.
* **Rendimiento Offline:** Base de datos local Room optimizada para navegación instantánea sin consumo excesivo de batería.
* **Actualizador Integrado:** Notificación y descarga directa de nuevas versiones.

---

## Arquitectura

* **Lenguaje:** Kotlin
* **Interfaz:** Jetpack Compose, Material 3
* **Persistencia:** Room Database, DataStore Preferences
* **Concurrencia:** Coroutines, StateFlow
* **Inyección de dependencias:** App Container Pattern
* **Tareas en segundo plano:** WorkManager, AlarmManager
