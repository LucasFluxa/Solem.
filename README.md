## ✨ Características Principales

* 📅 **Horario Personalizado Inteligente:** Visualización semanal o diaria de tus bloques de clases con notificaciones anticipadas de sala y horario.
* 🎓 **Malla Curricular Interactiva:** Explora tu plan de estudios, prerequisitos, asignaturas aprobadas y simula futuros semestres.
* 👨‍🏫 **Directorio de Profesores y Ramos:** Información completa sobre paralelos, salas, sedes (Casa Central, San Joaquín, Viña del Mar, Concepción) y evaluaciones.
* ⚡ **Rendimiento 100% Offline:** Base de datos local optimizada con Room para 0ms de tiempo de carga y consumo mínimo de batería.
* 🔄 **Actualizador Integrado:** Notificaciones y descarga directa de nuevas versiones sin necesidad de tiendas de aplicaciones.

---

## 🛠️ Tecnologías y Arquitectura

* **Lenguaje:** Kotlin 2.0+
* **UI:** Jetpack Compose + Material 3 (Diseño oscuro, fluido y minimalista)
* **Persistencia:** Room Database + DataStore Preferences
* **Asincronía:** Kotlin Coroutines + StateFlow / SharedFlow
* **Inyección de Dependencias:** Clean Container Pattern
* **Procesamiento en Segundo Plano:** Android WorkManager + AlarmManager
